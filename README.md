# 📝 Task Reminder Application

A Spring Boot–based Task Reminder application that helps users manage tasks efficiently with features like:

- User Authentication
- Task CRUD operations
- Task Status & Priority
- Card / Table / Calendar Views
- Deleted Tasks (Bin & Restore)
- Email Notifications (OTP & Reports)
- Profile Management with Image Upload

---

## 🛠 Tech Stack

- Java
- Spring Boot
- Spring Security
- Thymeleaf
- MySQL
- HTML, CSS, JavaScript

---

## 🚀 How to Run the Project

1. Clone the repository
2. Configure `application.properties`
3. Run the application:
   ```bash
   mvn spring-boot:run
